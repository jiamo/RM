## The argument

`Λ` has simple poles at `s = 0, 1` only, and Mathlib provides the entire function `Λ₀` with
`Λ(s) = Λ₀(s) − 1/s − 1/(1 − s)`. Multiplying by `s(s − 1)` clears both poles:

```
s(s − 1)Λ(s) = s(s − 1)Λ₀(s) − (s − 1) + s = s(s − 1)Λ₀(s) + 1,
```

so defining `Ξ` by the right-hand side makes it entire by construction, and the two agree off
`{0, 1}`.

At `s = 0` and `s = 1` the definition gives `Ξ = 1/2 ≠ 0`, so no zero of `Ξ` sits over a pole
of `Λ`. Elsewhere `Ξ(z) = 0 ⟺ Λ(s) = 0`. Since `Λ(s) = Γ_ℝ(s)ζ(s)` for `re s > 0` and `Γ_ℝ`
is zero-free there, `Λ(s) ≠ 0` for `re s ≥ 1` by Mathlib's
`riemannZeta_ne_zero_of_one_le_re`; the functional equation `Λ(1 − s) = Λ(s)` extends this to
`re s ≤ 0`. Hence the zeroes of `Ξ` are exactly the strip zeroes of `ζ`, transported by
`s = 1/2 + iz`. Under that transport `re s = 1/2 − im z`, so "`re s = 1/2` for every strip
zero" is literally "`im z = 0` for every zero of `Ξ`".

* **Non-vacuity of `riemannXi_eq_zero_iff`.** The right-hand side is *not* empty of content:
  `ζ` does have zeroes in the strip (the first is at `1/2 + 14.13…i`), so `Ξ` genuinely has
  zeroes, and the iff is a real classification rather than a statement about the empty set.
  Correspondingly `XiForm` is not vacuously true.
* **The two poles are checked, not assumed away.** The candidate exceptional points `s = 0`
  and `s = 1` (that is, `z = ∓ i/2`) are handled by direct computation from the definition:
  the factor `s(s − 1)` vanishes and `Ξ = 1/2`. This is exactly the place where the
  "manifestly entire" form pays off; had `Ξ` been defined as `s(s−1)Λ(s)/2`, Lean's junk
  value for `Λ` at its poles would have had to be argued about.
* **Direction check.** `Λ(s) = Γ_ℝ(s)ζ(s)` is used only for `re s > 0`; the case `re s ≤ 0`
  goes through `Λ(1 − s) = Λ(s)`, where `re(1 − s) ≥ 1`. Neither branch uses any unproved
  input beyond Mathlib's `riemannZeta_ne_zero_of_one_le_re` and the functional equation for
  the completed zeta function, both of which are Mathlib theorems, not statements of this
  repository.
* **Numerical sanity of the transport.** `z = 14.13…` corresponds to
  `s = 1/2 + 14.13…i`, which is on the critical line and has `im z = 0`; a hypothetical
  off-line zero `s = 0.6 + 14i` would correspond to `z = 14 − 0.1i`, with `im z = −0.1 ≠ 0`,
  matching `re s = 1/2 − im z`.
