# Evidence: the zero-counting lemma and the order-one growth of `ξ` (2026-08-20)

Row: `M1-XI-GROWTH` (new, `DONE_STRONG`).

## What is proved (without `sorry`)

`RiemannHypothesis/ZeroCountingLemma.lean` — a general complex-analysis estimate:

* `pow_three_card_mul_norm_le` : if `f` is holomorphic on the open ball `B(c, R)` and continuous
  on its closure, if `‖f z‖ ≤ M` on the circle `‖z − c‖ = R`, and if `S` is a finite set of
  zeroes of `f` with `‖a − c‖ ≤ R/4` for `a ∈ S`, then `3^|S| · ‖f c‖ ≤ M`.
* `card_le_log_div_log_three` : equivalently `|S| ≤ log (M / ‖f c‖) / log 3`.
* `finite_setOf_zeros`, `ncard_setOf_zeros_le` : the zero set of `f` in the ball of radius `R/4`
  is finite, of cardinality at most `log (M / ‖f c‖) / log 3`.

`RiemannHypothesis/XiGrowth.lean` — the completed zeta function in the `s`-variable:

* `xiFn s = ½ (s (s − 1) Λ₀(s) + 1)` (a definition), with `riemannXi z = xiFn (xiPoint z)`
  by `rfl`;
* `differentiable_xiFn` : `ξ` is entire;
* `xiFn_one_sub` : the functional equation `ξ(1 − s) = ξ(s)`;
* `xiFn_eq_completed` : `ξ(s) = ½ s (s − 1) Λ(s)` away from `s = 0, 1`;
* `xiFn_eq_zero_of_zeta` : every zero of `ζ` in the critical strip is a zero of `ξ`;
* `xiFn_two_ne_zero` : `ξ(2) ≠ 0`;
* `Gamma_le_exp_of_one_le`, `Gamma_le_exp_of_quarter_le` : `Γ(x) ≤ exp((x+1) log(x+1))` for
  `x ≥ 1`, and the same with a factor `4` for `x ≥ 1/4`;
* `norm_Gammaℝ_le` : `‖Γ_ℝ(s)‖ ≤ Γ(re s / 2)` for `re s > 0`;
* `norm_riemannZeta_le_sq` : `‖ζ(s)‖ ≤ 16‖s‖² + 2` for `re s ≥ 1/2` provided `re s ≥ 2` or
  `|im s| ≥ 3`;
* `norm_xiFn_le` : **`‖ξ(s)‖ ≤ exp (C (1 + ‖s‖) log (2 + ‖s‖))`** for an absolute constant `C`.

## The argument

The counting lemma is proved by dividing out one zero at a time and *not* by Jensen's formula.
If `f a = 0` with `‖a − c‖ ≤ R/4`, then `g = dslope f a` (which equals `z ↦ f z /(z − a)` away
from `a`, and is holomorphic across `a` by the removable-singularity theorem, Mathlib's
`Complex.differentiableOn_dslope`) satisfies `‖g‖ ≤ M/(3R/4)` on the circle `‖z − c‖ = R`,
because `‖z − a‖ ≥ 3R/4` there; and `‖g c‖ ≥ ‖f c‖/(R/4)`. Each such step multiplies the ratio
`M / ‖f c‖` by at least `3`, and the maximum modulus principle
(`Complex.norm_le_of_forall_mem_frontier_norm_le`) supplies the base case.

For the growth of `ξ`, on `re s ≥ 1/2` write `ξ(s) = ½ s(s−1) Γ_ℝ(s) ζ(s)` and bound the three
factors: `‖Γ_ℝ(s)‖ ≤ Γ(re s/2) ≤ 4 exp((‖s‖+1) log(‖s‖+1))`, and `‖ζ(s)‖ ≤ 16‖s‖² + 2` from the
Dirichlet-series bound for `re s ≥ 2` together with this repository's convexity bound
(`norm_riemannZeta_le_sixteen`) and near-line bound (`norm_riemannZeta_le_log_near_line`) for
`1/2 ≤ re s ≤ 2`, `|im s| ≥ 3`. The remaining region `1/2 ≤ re s ≤ 2`, `|im s| ≤ 3` is compact
and `ξ` is entire, so it is bounded there. The left half-plane follows from `ξ(1 − s) = ξ(s)`.

## What is *not* proved

* No *lower* bound on the growth of `ξ` is proved, so the order of `ξ` is not determined
  (it is `1`; only `≤ 1`, in the crude form above, is proved).
* The counting lemma counts zeroes **without multiplicity**; the version with multiplicity would
  need the local factorisation `f = (z − a)^m g`.
* The constant `C` in `norm_xiFn_le` is not explicit: the compact region is handled by a
  continuity argument.

## Adversarial revalidation: M1-XI-GROWTH

Second, independent pass.

* **Claim mode.** Everything is a `theorem`/`lemma` proved here, except `xiFn`, which is a
  `def`; it is pinned by `rfl` in `scripts/revalidation.lean`, as is the identity
  `riemannXi z = xiFn (xiPoint z)`. Nothing is assumed: no hypothesis of either file mentions
  the Riemann hypothesis or any unproved conjecture.
* **Non-vacuity of the counting lemma.** The hypothesis `f c ≠ 0` is essential and is not
  vacuous: it is verified in the application (`ξ(2) = Λ(2) ≠ 0`, from the repository's
  `completedRiemannZeta_ne_zero_of_one_le_re`). The conclusion is non-trivial: with
  `S = ∅` it degenerates to the maximum principle, and each additional zero costs a factor `3`.
* **Sanity check of the geometry.** The factor `3` comes from `R − R/4 = 3R/4` against
  `R/4`; the ratio of the two radii, `3`, is exactly what appears in `log(M/‖f c‖)/log 3`.
  Taking `f(z) = (z − c)^n` (no boundary bound is violated) gives `‖f c‖ = 0`, which is why
  `f c ≠ 0` must be assumed; taking `f(z) = ((z − c)/R)^n + ε` shows the count really can grow
  like `log M / log 3`, so the shape of the bound is right.
* **Non-vacuity of the growth bound.** `norm_xiFn_le` is stated for *all* `s : ℂ`, with no
  side condition, so it cannot be vacuous. Numerically `ξ(2) = Λ(2) = π^{-1} Γ(1) ζ(2) = π/6
  ≈ 0.524`, comfortably below `exp(C · 3 · log 4)`.
* **Where the estimates come from.** The `ζ` bounds used are proved in this repository
  (`Bounds`, `Convexity`, `NearLine`); the Gamma bound uses only Mathlib's monotonicity of `Γ`
  on `[2, ∞)` and `n! ≤ n^n`. In particular the crude bound `‖Γ(z)‖ ≤ Γ(re z)` loses the
  exponential decay of `Γ` on vertical lines, which is harmless here because we only claim an
  upper bound of order `exp(C|s| log|s|)`.
* **Statement pinning.** `scripts/revalidation.lean` writes out the counting lemma, `xiFn`,
  the functional equation and `norm_xiFn_le` in full and supplies the repository's declarations
  as the proof terms; `scripts/audit.sh` prints their axioms.
