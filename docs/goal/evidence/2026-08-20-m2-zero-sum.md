# Evidence: summability over the nontrivial zeroes, `∑_ρ 1/(1+γ²) < ∞` (2026-08-20)

Row: `M2-ZERO-SUM` (new, `DONE_STRONG`).

## What is proved (without `sorry`)

`RiemannHypothesis/ZeroSum.lean`:

* `nontrivialZeroSet = {s | ζ s = 0 ∧ 0 < re s ∧ re s < 1}` (a definition: all the zeroes of
  `ζ` in the open critical strip, of any height);
* `countable_nontrivialZeroSet` : **the set of nontrivial zeroes is countable**;
* `sum_inv_one_add_im_sq_le` : there is an absolute `B > 0` such that
  `∑_{ρ ∈ S} 1/(1 + (im ρ)²) ≤ B` for *every* finite set `S` of nontrivial zeroes;
* `summable_inv_one_add_im_sq` : **`∑_ρ 1/(1 + γ²)` converges**, the sum being over the
  nontrivial zeroes `ρ = β + iγ`;
* `summable_inv_one_add_norm_sq` : `∑_ρ 1/(1 + ‖ρ‖²)` converges;
* `exists_pos_le_norm_of_nontrivialZero` : the nontrivial zeroes are bounded away from `0`;
* `summable_inv_norm_sq` : **`∑_ρ 1/‖ρ‖²` converges**.

Zeroes are counted **without multiplicity** throughout, exactly as in `M2-ZERO-COUNT`.

## The argument

Everything is deduced from the Riemann–von Mangoldt upper bound `N(T) ≤ C T log T`
(`ncard_nontrivialZeros_le`, row `M2-ZERO-COUNT`), by a **dyadic decomposition**.

Write `blockIndex s = Nat.log 2 ⌊|im s|⌋₊`. Then `|im s| < 2^(blockIndex s + 1)` always, and
`4^(blockIndex s) ≤ (im s)²` as soon as `blockIndex s ≥ 1`, so that
`1/(1 + (im s)²) ≤ 4^(-blockIndex s)` for every `s` (the case `blockIndex s = 0` being
`1/(1 + t²) ≤ 1`).

For a finite set `S` of nontrivial zeroes, split `S` into the fibres of `blockIndex`
(`Finset.sum_fiberwise_of_maps_to`, the index set being `range (K+1)` for `K = S.sup blockIndex`).
The fibre over `k` consists of nontrivial zeroes of height at most `2^(k+1)`, so it has at most
`C · 2^(k+1) · log (2^(k+1)) ≤ C · 2^(k+1) · (k+1)` elements (using `log 2 ≤ 1`), and each of its
elements contributes at most `4^(-k)`. Hence the fibre contributes at most `2C (k+1) 2^(-k)`, and

  `∑_{k < K+1} (k+1) 2^(-k) = 4 − 2(K+3)2^(-(K+1)) ≤ 4`  (`sum_succ_div_two_pow`),

so `∑_{ρ ∈ S} 1/(1 + γ²) ≤ 8C` uniformly in `S`. `summable_of_sum_le` turns the uniform bound on
finite sums of a nonnegative function into summability over the subtype `↥nontrivialZeroSet`.

A decomposition into *unit* bands `n ≤ |γ| < n+1` would **not** work with only the global bound
`N(T) = O(T log T)` available: it gives `O(log n / n)` per band, which diverges. (The local bound
`N(T+1) − N(T) = O(log T)` of `M2-ZERO-COUNT-LOCAL` would work for bands, but only for `T ≥ 25`;
the dyadic route needs no case split.)

`∑_ρ 1/(1+‖ρ‖²)` follows by comparison, since `|γ| ≤ ‖ρ‖`. For `∑_ρ 1/‖ρ‖²` one needs the zeroes
to be bounded away from the origin: the zeroes with `|γ| ≤ 1` form a finite set
(`finite_nontrivialZeros 1`) and none of them is `0` (a zero has `re > 0`), so their minimal
modulus `δ` is positive, while every other zero has `‖ρ‖ ≥ |γ| > 1`; then
`1/‖ρ‖² ≤ (1 + δ^(-2)) · 1/(1 + ‖ρ‖²)`.

## What is *not* proved

* Nothing here asserts that any nontrivial zero **exists**; if the set were empty every
  statement above would still hold (and be vacuous). The content is the bound. (Existence is
  proved separately, in row `M2-ZERO-EXISTS`,
  [`docs/goal/evidence/2026-08-20-m2-zero-exists.md`](2026-08-20-m2-zero-exists.md); it is not
  used anywhere in this row.)
* Multiplicities are ignored. The classical statements `∑_ρ 1/|ρ|^(1+ε) < ∞` count zeroes with
  multiplicity; that refinement needs the order of vanishing of `ξ`, which is not developed here.
* The Hadamard product `ξ(s) = e^(a+bs) ∏_ρ (1 − s/ρ) e^(s/ρ)`, whose convergence this
  summability is the analytic input to, is **not** proved.
* The constants are not explicit (they inherit the non-explicit constant of `norm_xiFn_le`).
* Nothing here bears on the location of the zeroes, so the row does not touch the Riemann
  hypothesis.

## Adversarial revalidation: M2-ZERO-SUM

Second, independent pass.

* **Claim mode.** `nontrivialZeroSet` is a `def`, pinned by `rfl` in `scripts/revalidation.lean`;
  the results are `theorem`s proved in this repository, and are pinned there in full. No
  hypothesis mentions the Riemann hypothesis and no statement implies it: all four are equally
  true whether or not the zeroes lie on the critical line.
* **Vacuity check.** The danger here is the opposite of the usual one: a summability statement
  over an *empty* index set is trivially true. The set is not known here to be nonempty, and the
  evidence says so explicitly (nonemptiness is established independently by `M2-ZERO-EXISTS`);
  but the proof does not use emptiness anywhere — the bound `8C` is
  derived for an arbitrary finite subset, so it is the genuine quantitative statement, and it
  would be false if the counting bound `N(T) = O(T log T)` were replaced by, say, `N(T) = O(T²)`.
* **Direction check.** Every inequality in the chain is an upper bound on a nonnegative
  quantity, and the final step (`summable_of_sum_le`) consumes exactly a uniform upper bound on
  finite sums, so a reversed inequality could not have produced a summability conclusion.
* **Where the strength of the input is used.** `∑_ρ 1/(1+γ²)` converges precisely because
  `N(T) = O(T log T)` with `T log T = o(T²)`; the proof would break with a bound `N(T) = O(T²)`,
  as the dyadic blocks would then contribute a constant each. This is a real use of `M2-ZERO-COUNT`
  and not a repackaging of it.
* **Sanity check of the order of magnitude.** With the true `N(T) ~ (T/2π) log T` the sum
  `∑_ρ 1/(1+γ²)` behaves like a convergent sum of order `∑ log n / n²`, and is small; the proved
  bound `8C` is far larger, and no sharpness is claimed.
* **Countability.** `countable_nontrivialZeroSet` is proved from `finite_nontrivialZeros` by
  covering the strip with the heights `T = n`, `n : ℕ`; the cover is exhaustive because every
  complex number has a finite imaginary part (`exists_nat_ge`).
* **Statement pinning.** `scripts/revalidation.lean` writes out `nontrivialZeroSet`,
  `countable_nontrivialZeroSet`, `summable_inv_one_add_im_sq`, `summable_inv_one_add_norm_sq`
  and `summable_inv_norm_sq` in full and supplies the repository's declarations as the proof
  terms; `scripts/audit.sh` prints their axioms.
