# M1-OFF-LINE — at most a third of the zeroes lie off the critical line

Date: 2026-08-21
File: `RiemannHypothesis/OffLine.lean`

## Claim

The two-thirds theorem of `RiemannHypothesis.Zeta23Bridge`, read from the other side, bounds the
zeroes that could violate the Riemann hypothesis. Writing `N` for the number of nontrivial zeroes
of `ζ` in a window counted with multiplicity, `N_d` for the distinct ones, `N₀*` for the distinct
ones on the critical line and `N_off` for the distinct ones off it:

* `windowZerosOffLine`, `windowCountOffLine` — the off-line zeroes of a window `(T₁, T₂]` and
  their number;
* `windowCountOffLine_add_windowCountOnLine` — `N_off + N₀* = N_d`;
* `one_third_off_critical_line` — for every `ε > 0` and all large `T`,
  `N_off(T, 2T) ≤ (1/3 + ε)·N(T, 2T)`;
* `one_third_off_critical_line_cumulative` — the same over the windows `(0, T]`;
* `offCriticalZeroCount` and `offCriticalZeroCount_add_criticalZeroCount` — the corresponding
  count in the `Partial.lean` counting functions, with `N_off(T) + N₀(T) = N(T)`;
* `eventually_offCriticalZeroCount_le` — for every `ε > 0`, eventually
  `N_off(T) ≤ (1/3 + ε)·N(T)`;
* `limsup_offCriticalZeroCount_div_le_one_third` — `limsup N_off(T)/N(T) ≤ 1/3`.

## Proof

Purely combinatorial given the inputs. Each window carries finitely many zeroes
(`windowZeros_finite`, `openWindowZeros_finite`), so the count splits as a disjoint union over
`re ρ = 1/2` versus `re ρ ≠ 1/2` (`Set.ncard_union_eq`). Then
`N_off = N_d − N₀* ≤ N − N₀* ≤ N − (2/3 − ε)N = (1/3 + ε)N`, using
`windowCountDistinct_le_windowCount` and `two_thirds_on_critical_line`. The `limsup` form follows
from the `eventually` form, the quotient being non-negative, hence cobounded above.

## Scope — what is *not* claimed

The bound is a `liminf`/`limsup` statement with no effective `T₀`, and it says nothing about
which zeroes are off the line. The Riemann hypothesis is the assertion that the off-line count is
*zero*; that remains open and unproved in this repository.

* `#print axioms` for `one_third_off_critical_line`,
  `one_third_off_critical_line_cumulative`, `eventually_offCriticalZeroCount_le` and
  `limsup_offCriticalZeroCount_div_le_one_third` reports exactly
  `[propext, Classical.choice, Quot.sound]`.
* The claims are pinned in `scripts/revalidation.lean`: each statement is written out in full
  there, with the repository's declaration supplied as the proof term, so a weakened or renamed
  declaration stops that file from elaborating.
* The definitions are not vacuous: `windowZerosOffLine` is cut out of `windowZeros` by
  `ρ.re ≠ 1/2`, and `offCriticalZeroCount` is cut out of the `zeroCount` set by the same
  condition; the two splitting lemmas show the pieces really do add up to the full counts, so a
  degenerate definition would contradict them.
* No hypothesis of the form "RH is false" appears anywhere; the statements are unconditional.
