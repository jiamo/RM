# M2-ZERO-GAPS — the gaps between consecutive zero ordinates

Date: 2026-08-25
File: `RiemannHypothesis/ZeroGaps.lean`
Predecessor: `docs/goal/evidence/2026-08-25-m2-zero-ordinate.md`

## Claim

With `γ_n = nthZeroOrdinate n` the ordinate of the `n`-th zero of `ζ` in the upper half plane
(counted with multiplicity) and `zeroGap n = γ_{n+1} − γ_n`:

* `monotone_nthZeroOrdinate`, `zeroGap_nonneg` — the ordinates increase, so the gaps are
  non-negative;
* `nthZeroOrdinate_zero` — `γ_0 = 0`;
* `sum_zeroGap` — the gaps telescope: `∑_{n < N} zeroGap n = γ_N`;
* `tendsto_nthZeroOrdinate_div_nat` — `γ_n / n → 0`;
* `tendsto_avg_zeroGap` — **the average gap tends to `0`**;
* `infinite_setOf_zeroGap_lt` — for every `ε > 0` infinitely many gaps are smaller than `ε`;
* `infinite_setOf_zeroGap_mul_log_lt` — **`liminf (γ_{n+1} − γ_n) log γ_n ≤ 2π`**: for every
  `ε > 0` there are infinitely many `n` with `(γ_{n+1} − γ_n) log γ_n < 2π + ε`;
* `le_sum_zeroGap_mul_log_succ` — `∑_{n < N} (γ_{n+1} − γ_n) log γ_{n+1} ≥ γ_N log γ_N − γ_N`;
* `tendsto_log_nthZeroOrdinate_succ_div` — `log γ_{n+1} / log γ_n → 1`;
* `infinite_setOf_zeroGap_mul_log_gt` — **`limsup (γ_{n+1} − γ_n) log γ_n ≥ 2π`**: for every
  `ε > 0` there are infinitely many `n` with `(γ_{n+1} − γ_n) log γ_n > 2π − ε`.

## Proof

* Monotonicity: `nthOrdinateSet m ⊆ nthOrdinateSet n` for `n ≤ m`, so the infima increase.
  `γ_0 = 0` because `nthOrdinateSet 0 = [0, ∞)`.  The telescoping identity is
  `Finset.sum_range_sub` together with `γ_0 = 0`.
* `γ_n / n → 0` is `γ_n log n / n → 2π` (from `M2-ZERO-ORDINATE`) multiplied by
  `(log n)⁻¹ → 0`; dividing the telescoping identity by `N` gives the average gap statement.
* Both "infinitely often" statements come from one elementary principle
  (`infinite_setOf_lt_of_avg_le`): if the partial averages `(1/N) ∑_{n<N} f n` are eventually at
  most `L` and `L < c`, then `f n < c` for infinitely many `n`.  Indeed if `f n ≥ c` for all
  `n ≥ N₀`, splitting `range M` at `N₀` gives `∑_{n<M} f n ≥ K + c (M − N₀)` with `K` a fixed
  constant, so the averages are at least `K/M + c(1 − N₀/M) → c > L`, a contradiction.
* For the unweighted statement the averages tend to `0`, so they are eventually below `ε/2 < ε`.
* For the weighted `liminf` statement, monotonicity of `γ` and of `log` on `[0, ∞)` gives
  `∑_{n<N} (γ_{n+1} − γ_n) log γ_n ≤ (∑_{n<N} (γ_{n+1} − γ_n)) log γ_N = γ_N log γ_N`
  once `γ_N ≥ 1`, and `γ_N log γ_N / N → 2π`, so the averages are eventually at most
  `2π + ε/2 < 2π + ε`.
* The `limsup` statement uses the dual principle (obtained from the first by replacing `f` with
  `−f`) and a matching *lower* bound for the weighted sums.  For `h(x) = x log x − x` and
  `0 ≤ a ≤ b` one has `h(b) − h(a) ≤ (b − a) log b`: this is `a log(a/b) + (b − a) ≥ 0`, which
  follows from `log(b/a) ≤ b/a − 1`.  Telescoping over `n < N`, with `h(γ_0) = h(0) = 0`, gives
  `∑_{n<N} (γ_{n+1} − γ_n) log γ_{n+1} ≥ γ_N log γ_N − γ_N`, whose quotient by `N` tends to
  `2π − 0 = 2π`; so infinitely many `n` satisfy `(γ_{n+1} − γ_n) log γ_{n+1} > 2π − ε`.
* To restore the standard weight `log γ_n`, combining `log γ_n / log n → 1` (shifted and
  unshifted) with `log(n+1)/log n → 1` gives `log γ_{n+1} / log γ_n → 1`; if the gaps weighted
  by `log γ_n` were eventually at most `2π − ε`, those weighted by `log γ_{n+1}` would be
  eventually at most `(1 + δ)(2π − ε) = 2π − ε + ε/4 < 2π − ε/2`, contradicting the previous
  paragraph.

## Scope — what is *not* claimed

* Zeroes are counted **with** multiplicity, and only those of positive ordinate are counted; a
  zero of multiplicity `m` contributes `m − 1` gaps equal to `0`, so `infinite_setOf_zeroGap_lt`
  would be trivial if `ζ` had infinitely many multiple zeroes.  It is *not* claimed here that
  the zeroes are simple, nor that infinitely many gaps are strictly positive.
* No quantitative improvement over `liminf ≤ 2π` or `limsup ≥ 2π` (that is, no result of the
  form
  `liminf (γ_{n+1} − γ_n) log γ_n < 2π`, which is what the literature on small gaps aims at) is
  claimed, and nothing here bears on the Riemann hypothesis.

## Adversarial revalidation: M2-ZERO-GAPS

* `#print axioms` reports exactly `[propext, Classical.choice, Quot.sound]` for
  `monotone_nthZeroOrdinate`, `sum_zeroGap`, `tendsto_nthZeroOrdinate_div_nat`,
  `tendsto_avg_zeroGap`, `infinite_setOf_zeroGap_lt`, `infinite_setOf_zeroGap_mul_log_lt`,
  `tendsto_log_nthZeroOrdinate_succ_div` and `infinite_setOf_zeroGap_mul_log_gt`.
* The two "infinitely often" statements are about `Set.Infinite` of a set of indices, so they
  cannot be satisfied by finitely many accidental indices; and `γ_n → ∞`
  (`tendsto_nthZeroOrdinate_atTop`) shows the indices correspond to infinitely many distinct
  heights.
* The weighted statements are not vacuous: the weight `log γ_n` tends to `+∞`, so
  `zeroGap n * log γ_n < 2π + ε` is a genuine restriction on the gap, of the correct order
  `2π / log γ_n`; and for `ε < 2π` the inequality `zeroGap n * log γ_n > 2π − ε` forces
  `zeroGap n > 0`, so the `limsup` statement exhibits infinitely many *strictly positive* gaps,
  of the same order.
* The two weighted statements are consistent and jointly sharp: they pin the `liminf` and the
  `limsup` of `(γ_{n+1} − γ_n) log γ_n` on opposite sides of the single value `2π`, which is
  what the counting asymptotic predicts for the average.
* The helper `infinite_setOf_lt_of_avg_le` assumes nothing about the sign of `f`; the finitely
  many initial terms are carried along as the constant `K` and disappear in the limit, so no
  hidden positivity hypothesis is used.
* The statements are unconditional: they take no unproved `Prop` of this repository as a
  hypothesis, and the module adds no row to `docs/goal/conditional-theorems.txt`.
