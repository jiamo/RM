## Adversarial revalidation: M2-VON-KOCH

A second pass, made after CI, independently of the first.

**The statement.**
* `chebyshevBoundForm_iff_zetaForm` has the type `RiemannHypothesis.ChebyshevBoundForm ↔
  RiemannHypothesis.ZetaForm`, and both names resolve to the library's definitions.
* The library modules are compiled from this repository's source in the same CI run
  (28 modules).
* If the tree declared either name, importing both would be a duplicate-declaration error. The
  compile succeeded, so neither is shadowed.

**Statement pinning.**
* `scripts/revalidation.lean` is compiled with the library, which does not import the tree, so
  it cannot pin these theorems.
* The pin is instead the theorem's own type, which mentions only library definitions, together
  with `analytic.sh`. That script requires exactly one axiom report per `#print axioms` line
  (6 for this file), so a renamed or deleted theorem fails CI.
* A *weakened* statement would not be caught mechanically. The statement is written out above
  for comparison.

**Hypotheses.**
* `chebyshevBoundForm_of_zetaForm` takes only `h : ZetaForm`.
* `h` is load-bearing: it is used in `re_eq_half`, to get `‖u^ρ‖ = u^{1/2}` and
  `‖ρ‖ ≥ (j+1)/2`.
* `ZetaForm` is not vacuous: it has an external proof.
* The tree's constants `C`, `C_w` come with `0 < C`, `0 < C_w` from the two closed theorems.
  The constant `K₁ = ∑_{|γ|<1} m_ρ/‖ρ‖` is shown `≥ 0`.

**The tree's definitions are the intended ones.** This is checked by the proofs, not assumed:
* `psi0_natCast` proves that `PI.psi0` at `n` is `ψ(n) − n`, by `rw`/`simp` from the
  definition;
* `re_eq_half` destructures `PI.ZerosBelow` into `0 < re ∧ re < 1 ∧ |im| < T ∧ L ρ = 0`, and
  `L(s, 1 mod 1) = ζ(s)` is Mathlib's `LFunction_modOne_eq`.

In any case the final statements mention only library definitions, so the meaning of the
tree's intermediate definitions cannot change what was proved.

**Constants, by hand** (n ≥ 2, L = log n ≥ log 2 > 0):
1. `log(n+2) ≤ log(2n) = log 2 + L < 1 + L`, since `n + 2 ≤ 2n` and `log 2 < 0.7`.
2. `n·log²(n²)/n + log n + K₁ = 4L² + L + K₁ ≤ (5+K₁)(1+L)²`. The difference is
   `5 + 9L + L² + 2K₁L + K₁L² ≥ 0`.
3. By (1) and (2), using `1 ≤ √n`:
   `|ψ(n) − n| ≤ √n·(4C_w + C(5+K₁))·(1+L)²`.
4. `L ≤ (2/ε)·n^{ε/2}` (Mathlib's `log_le_rpow_div` with exponent `ε/2`), and
   `1 ≤ n^{ε/2}`. So `1 + L ≤ (1+2/ε)·n^{ε/2}` and `(1+L)² ≤ (1+2/ε)²·n^ε`.
5. Hence `|ψ(n) − n| ≤ (4C_w + C(5+K₁))(1+2/ε)²·n^{1/2+ε}`. The theorem's constant is
   `max 1 (that)`.
6. Small cases: `n = 0`: `ψ(0) = 0` (empty sum), and `|0 − 0| = 0`. `n = 1`: `ψ(1) = Λ(1) = 0`,
   and `|0 − 1| = 1 ≤ max 1 (…) · 1`. Both are covered by the `max 1`.
7. Numerical sanity at `ε = 0.1`, `n = 10⁶`:
   * `(1+L)² ≈ (14.8)² ≈ 219`;
   * `(1+2/ε)²·n^ε = 441 · 3.98 ≈ 1755 ≥ 219`. ✓

**The window covering** (`sum_mult_div_norm_le`).
* A zero with `⌊|γ|⌋ = j` has `j ≤ |γ| < j+1`, so `|γ − j| < 1` if `γ ≥ 0` and `|γ + j| < 1`
  if `γ < 0`. Each fibre therefore lies in the two windows centred at `±j`, each of
  multiplicity mass `≤ C_w log(j+2)`.
* `‖ρ‖ ≥ max(1/2, j) ≥ (j+1)/2`.
* So the fibre contributes `≤ 2C_w log(⌈T⌉+2) · 2/(j+1)`. Summing over `j < ⌈T⌉` gives
  `4C_w log(⌈T⌉+2) · H_{⌈T⌉} ≤ 4C_w log(⌈T⌉+2)(1 + log⌈T⌉)` (Mathlib's
  `harmonic_le_one_add_log`). ✓
